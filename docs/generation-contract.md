# Generation Contract

## Deterministic responsibilities

The deterministic generator owns all behavior that can be represented by a supported specification primitive.

Examples:

```yaml
- id: V1
  type: required
  property: AccountNumber
```

must always map to the same framework primitive for a given generator and framework version.

Deterministic generation includes:

- Standard validators
- Standard business-rule handlers
- Side-effect mappings
- Dependency-injection registration
- Endpoint/controller integration
- Framework descriptors
- Serialization metadata
- OpenAPI metadata
- Test scaffolding
- Generation manifest

## AI responsibilities

AI is allowed to:

1. Interpret a completed requirements template into `MaintenanceServiceSpec`.
2. Identify ambiguity and propose clarification questions.
3. Generate a bounded custom-rule handler when the formal specification explicitly requests one.
4. Generate or augment acceptance scenarios from explicitly stated behavior.
5. Explain semantic differences between specification revisions.

AI is not allowed to:

- Invent missing business behavior.
- Modify framework infrastructure.
- Select transaction or idempotency behavior silently.
- Put arbitrary expression strings into the specification.
- Generate standard framework plumbing that has a deterministic emitter.
- Bypass validation, compilation, analyzers, or tests.

## Generated file ownership

Every generated file must contain:

```csharp
// <auto-generated>
// Generated from: AccountMaintenance.maintenance.yaml
// Generator version: <version>
// Do not edit this file directly.
// </auto-generated>
```

Manual extensions must use a separate partial class or framework extension interface.

## Manifest

Each generation creates a manifest similar to:

```json
{
  "templateHash": "...",
  "specificationHash": "...",
  "schemaVersion": 1,
  "frameworkVersion": "...",
  "generatorVersion": "...",
  "promptVersion": "...",
  "model": "...",
  "generatedFiles": []
}
```

The `model` and `promptVersion` fields are required only when AI participated in the current generation step.
